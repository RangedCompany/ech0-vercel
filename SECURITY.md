# Signalement de sécurité

Signaler une vulnérabilité du portage via le [formulaire privé du fork](https://github.com/RangedCompany/ech0-vercel/security/advisories/new). Si le formulaire est indisponible, contacter un mainteneur par un canal privé.

Indiquer la révision, l’environnement, l’impact et les étapes minimales de reproduction. Retirer les jetons, clés et données personnelles des pièces jointes. Coordonner la divulgation avec les mainteneurs une fois le correctif disponible.
