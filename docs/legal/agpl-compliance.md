# Licence et accès au code source

Ech0 Vercel est distribué sous [AGPL-3.0 ou ultérieure](../../LICENSE). Conserver les mentions d’attribution dans [NOTICE](../../NOTICE).

Le service doit proposer à ses utilisateurs l’accès au code source correspondant à la révision qu’il exécute. Le build Vercel renseigne le commit et l’URL du fork pour l’écran d’information. Pour une distribution modifiée, remplacer ces valeurs par celles du code effectivement déployé.
