# Code de conduite

Les échanges autour d’Ech0 Vercel doivent rester respectueux. Les critiques portent sur le travail. Le harcèlement, les menaces, les propos discriminatoires et la divulgation de données personnelles sont interdits.

Signaler un comportement problématique directement à un mainteneur par un canal privé. Selon les faits, les mainteneurs peuvent retirer un contenu, avertir un participant ou suspendre sa participation.

Ce texte est adapté du Contributor Covenant, version 2.1.
