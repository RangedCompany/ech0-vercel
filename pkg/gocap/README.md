# GoCap

Bibliothèque Go d’épreuve de travail utilisée pour les commentaires publics. Le client résout un challenge puis présente les solutions pour obtenir un jeton de validation. Les réglages du serveur contrôlent la difficulté, la durée des jetons et les limites d’appels.

Voir [l’architecture](ARCHITECTURE.md) et les variables `ECH0_COMMENT_CAPTCHA_*` dans [la configuration](../../internal/config/config.go).
