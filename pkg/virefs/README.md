# VireFS

Bibliothèque Go d’accès aux fichiers locaux et aux objets S3. Elle expose des opérations par clé et des URL signées sur les moteurs compatibles. Ech0 assemble ses fournisseurs et applique ses propres règles de visibilité dans `internal/storage`.

Pour changer de fournisseur sur une instance, suivre le [guide de migration des médias](../../docs/usage/storage-migration.md).
