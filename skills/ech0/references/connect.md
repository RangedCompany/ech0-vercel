# Connexions entre instances

```sh
ech0 connect list --json
ech0 connect info --json
ech0 connect health --json
ech0 connect add --connect-url https://pair.example.org
```

L’ajout et le retrait exigent un compte administrateur et les droits associés. Après confirmation, utiliser `ech0 connect delete --id <uuid> --yes`.
