# Confidentialité

Ech0 stocke les publications, médias et commentaires dans les services configurés par le responsable de l’instance. Le portage Vercel utilise une base Turso et un bucket R2. Si une instance active un fournisseur de connexion ou d’intelligence artificielle, les données transmises à ce service suivent ses propres conditions.

Pour savoir quelles données sont conservées ou demander leur suppression, s’adresser au responsable de l’instance utilisée.
